# Woloshin Club — Copy System (RU · первичный)

> Язык: **русский (RU)** — естественный литературный русский, ритм-первый, длинные фразы с дыханием.
> Не молдавский, не калька с румынского. Не булгаковский пафос — Курáль, Soho House, Aman.
> Структура: та же, что в `copy/out.md` (8 секций, A–H), для 1:1 посадки в HTML сверху вниз.
> ★ = рекомендованная (A/B primary). Остальные два — on-brand альтернативы.

> Конвенции типографики (из `woloshin.css`):
> **eyebrow** — Inter, 18px, tracking 0.28em, uppercase, muted.
> **headline** — Cinzel, 88px, gold/cream, uppercase.
> **italic / subhead** — Cormorant Garamond italic, 34px, cream/muted.
> **body** — Inter, 24px, muted.
> **price** — Inter Light, 96px, gold-bright.
> **caption** — Inter, 18px, tracking 0.12em, uppercase, warm-muted.

## WORD CHOICE GUIDE

### Запрещено (дёшево, общее, транзакционное)

| ❌ Не писать | Почему |
|---|---|
| `абонемент`, `подписка`, `абонент` | превращает принадлежность в сервис |
| `скидка`, `снижка`, `дисконт`, `промо-акция`, `спецпредложение` | язык супермаркета |
| `лучший`, `крупнейший`, `премиальный` (как прилагательное) | пустой суперлатив |
| `идеальный`, `исключительный`, `революционный`, `уникальный` | обещание без покрытия |
| `доступная цена`, `выгодно`, `всего за`, `дёшево` | убивает позиционирование |
| `преимущества`, `бенефиты` | язык HR / страховок |
| `купить сейчас`, `не упустите`, `успейте`, `спешите` | давление, реклама |
| `клиент`, `пользователь`, `потребитель` | человек — член клуба, не клиент |
| `карта члена`, `VIP-карта` | опошляет |
| `бонус`, `экстра`, `сюрприз` | язык ТВ-рекламы |
| `давай`, `напишите нам`, `свяжитесь` | разговорно, не по-членски |
| `скидочная карта`, `акция`, `распродажа` | язык распродаж |

### Предпочтительно (лексика клуба, дома, ритуала)

| ✅ Использовать | Вместо |
|---|---|
| `сообщество`, `круг`, `стол` | группа, команда |
| `член клуба`, `гость` | клиент, абонент |
| `доступ`, `привилегия`, `право` (дома) | скидка, бенефит |
| `дом`, `комплекс`, `Woloshin Banya` | офис, локация |
| `выделенный администратор` | менеджер счёта, ассистент |
| `ритуал`, `жест`, `обычай дома` | промо-акция, бонус |
| `подарок`, `дар дома` | приз, награда |
| `взнос`, `личный счёт`, `депозит` | налог, оплата, стоимость |
| `издание`, `Издание I`, `Издание II` | версия, год |
| `разговор`, `совместное время`, `ужин` | встреча, корпоратив |
| `здесь`, `у нас`, `в доме` | наш офис, компания |
| `принимают`, `носят` | покупают, приобретают |
| `пятьдесят`, `пятьдесят человек` | немного, несколько (подрывает редкость) |

### Заметки о тоне (помнить при любой правке)

1. **Второе лицо, единственное число.** «Вы за столом.» Никогда «вы, уважаемые члены».
2. **Короткая фраза в конце абзаца.** Длинное предложение строит; короткое — закрывает. «Woloshin Club не покупается. Его принимают — и носят.»
3. **Числа прописью в поэтическом контексте** (`пятьдесят членов`) и цифрами в функциональном (`50 000 MDL`). Никогда микс в одном предложении.
4. **MDL не скрывается, но и не оправдывается.** Показывается один раз, сдержанно, потом говорим о том, что открывается.
5. **«Выделенный администратор» — центральная часть.** Если абзац нужно убрать — не убирайте этот.
6. **Никаких риторических вопросов в заголовках.** Заголовки — утверждения. Вопросы звучат как реклама.
7. **Italic — это дыхание, не пояснение.** Курсив Корморанта — для эмоции и ритма, не для того, чтобы объяснять только что сказанное.
8. **Клуб маленький, не «эксклюзивный».** Редкость показывается через числа и жесты, не через слова.
